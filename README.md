# 🚀 **Ansh Jain's Portfolio**  

A clean and modern personal portfolio website built using **React.js**. This portfolio showcases my skills, projects, and professional background in a sleek, responsive design.  

🌐 **[Live Demo](https://portfolio-main-six-mauve.vercel.app/)** 


## 📖 **About the Project**  
This is a personal portfolio website designed to present my professional background, technical skills, and projects in an interactive and visually appealing format.  

### 🌟 **Key Features:**
- Clean and modern UI with a dark theme  
- Professional Skillset section with hover effects  
- "Get to Know Me" section to share personal and professional details  
- Projects section to display my work and experience  
- Resume download option  
- Smooth scrolling and responsive design  


## 🛠️ **Tech Stack**  
- **Frontend:** React.js, JavaScript  
- **Styling:** CSS  
- **Deployment:** Vercel  


## 🚀 **Getting Started**  

### **1. Clone the Repository**  
```bash
git clone [repo-url]
```

### **2. Navigate to the Project Directory**  
```bash
cd portfolio
```

### **3. Install Dependencies**  
```bash
npm install
```

### **4. Start the Development Server**  
```bash
npm start
```
The site will be live at:  
👉 `http://localhost:3000`  

---

## 🌍 **Deploying to Vercel**  
1. Create a new project on [Vercel](https://vercel.com).  
2. Link the repository.  
3. Deploy using Vercel’s auto-deployment system.
